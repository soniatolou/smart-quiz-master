1. INLEDNING
----------------------------------------------------------------
Detta dokument beskriver testplanen för Smart Quiz Master.
Testplanen specificerar scope, mål, resurser, schema och
ansvar för testarbetet.


2. SYFTE OCH MÅL
----------------------------------------------------------------
Målet med testningen är att säkerställa att:

  - Alla klasser fungerar korrekt var för sig (enhetstester)
  - Felaktig inmatning hanteras på ett kontrollerat sätt
  - Poängberäkning och highscore-sparning fungerar korrekt
  - Hela spelflödet fungerar från start till slut
  - Systemet inte kraschar vid oväntade indata


3. SCOPE
----------------------------------------------------------------
Inkluderat i testningen:
  [x] Validator – validate_answer() och validate_player_name()
  [x] QuestionProvider – laddning och sökning av frågor
  [x] ScoreTracker – poängräkning, procent, highscore
  [x] GameEngine – spelflöde med mockade beroenden

Exkluderat från automatiserad testning:
  [ ] main.py (ingångspunkt, ej affärslogik)
  [ ] Grafiskt gränssnitt (finns ej)
  [ ] Nätverkskommunikation (finns ej)

  V02   validate_answer        Giltigt svar "4" → returnerar 3
  V03   validate_answer        Inmatning med mellanslag → OK
  V04   validate_answer        Tom sträng → ValueError (empty)
  V05   validate_answer        Endast mellanslag → ValueError
  V06   validate_answer        None → ValueError

6.2 QuestionProvider (test_question_provider.py)
  ID    Metod                  Beskrivning
  ----  ---------------------  --------------------------------
  Q01   load_questions         Giltig JSON-fil → 3 frågor laddas

6.3 ScoreTracker (test_score_tracker.py)
  ID    Metod                  Beskrivning
  ----  ---------------------  --------------------------------
  S01   get_score              Startpoäng är 0
  S02   add_correct            Poäng ökas med 1
  S03   add_incorrect          Poäng förblir 0
  S04   get_total              Total ökar vid rätt och fel
  S05   get_percentage         2 rätt, 1 fel → 66.7%
  S06   get_percentage         Inga svar → 0.0%
  S07   reset                  Poäng och total återställs till 0
  S08   save_highscore         JSON-fil skapas
  S09   save_highscore         Innehållet är korrekt (spelare,
                               poäng, total)
  S10   get_highscores         Sorterat fallande efter poäng
  S11   get_highscores         Ingen fil → tom lista

6.4 GameEngine (test_game_engine.py)
  ID    Beskrivning
  ----  -------------------------------------------------------
  G01   Rätt svar → add_correct() anropas, ej add_incorrect()
  G02   Fel svar → add_incorrect() anropas, ej add_correct()
  G03   Inga frågor → spelet avslutas tidigt utan poänganrop
  G04   Ogiltig inmatning upprepas tills giltigt svar ges
  G05   save_highscore() anropas en gång efter alla frågor
